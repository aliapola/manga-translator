# مترجم مانگا / مانهوا / مانهوآ (Android)

اپ اندروید برای ترجمهٔ متن روی صفحه (مانگا، مانهوا، مانهوآ). متن با ML Kit
تشخیص داده می‌شود و ترجمهٔ **MyMemory** مستقیم روی همان حباب نمایش داده می‌شود.

## معماری
```
ScreenCaptureService -> گرفتن فریم از صفحه (MediaProjection)
OcrProcessor         -> ML Kit OCR (لاتین/ژاپنی/کره‌ای/چینی)، کوچک‌سازی فریم، اجرا روی Dispatchers.Default
TranslationManager   -> فقط MyMemory: درخواست موازی + کش RAM/دیسک + فیلتر + OkHttp مشترک
web/ChapterTranslator + WebReaderScreen -> ترجمه کل چپتر داخل WebView
OverlayService       -> دکمه شناور + نمایش تدریجی ترجمه‌ها روی تصویر
SettingsStore        -> تنظیمات (DataStore)
```

## خواندن چپتر از وب (ترجمه کل چپتر)
از صفحه اصلی «خواندن چپتر از وب» را باز کنید، آدرس چپتر را بزنید و «ترجمه کل چپتر» را بزنید.
- تصاویر چپتر (با پشتیبانی lazy-load) پیدا و با User-Agent/Referer/کوکی خود WebView دانلود می‌شوند.
- تصاویر بلند وبتون تکه‌تکه (۱۶۰۰px با هم‌پوشانی) OCR می‌شوند و متن‌ها موازی با MyMemory ترجمه می‌شوند.
- تصویر ترجمه‌شده در کش ذخیره و جای تصویر اصلی در همان صفحه قرار می‌گیرد (از تصویر قابل‌مشاهده شروع می‌شود).
- دکمه «نمایش اصل/ترجمه» برای مقایسه؛ باز کردن دوباره همان چپتر از کش و فوری است (کش ۳ روزه).

## بهینه‌سازی‌های سرعت
1. ترجمهٔ موازی همهٔ حباب‌ها (حداکثر ۶ درخواست همزمان)
2. کش دائمی ترجمه‌ها (RAM + SharedPreferences)
3. نمایش تدریجی: هر ترجمه به محض رسیدن روی صفحه کشیده می‌شود
4. فیلتر عدد/علامت/نویز OCR و حذف متن‌های تکراری قبل از ارسال
5. یک OkHttpClient مشترک با Keep-Alive و HTTP/2
6. OCR: ساخت یک‌باره و پیش‌گرم‌کردن Recognizer، کوچک‌کردن فریم، اجرا روی Dispatchers.Default

## نکات
- نیاز به اینترنت دارد (مجوز INTERNET). ترجمه‌های کش‌شده بدون اینترنت هم نمایش داده می‌شوند.
- MyMemory: ۵٬۰۰۰ کلمه در روز؛ با ثبت ایمیل در تنظیمات ۵۰٬۰۰۰ کلمه.
- ترجمه عیناً و بدون سانسور انجام می‌شود.

## ساخت
Android Studio (JDK 17) یا `./gradlew assembleDebug`.
